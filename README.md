# 云智仿

云乘见的算法仿真系统，用于检验响应型接驳公交的派单与调度策略。它与乘客端同源共用站点、路网和运营边界数据，可完全独立运行，不依赖任何后端服务。

## 功能

- **真实路网**：站点吸附到折线道路网，按真实里程计算最短路径
- **站台模型**：路侧对侧站台、地铁出入口、车辆停靠方向与顺路落客规则
- **需求仿真**：按站点级别生成全天呼叫，可调整规模与随机种子
- **三视角**：司机视角看车辆轨迹，用户视角看订单全链路，宏观视角看调度指标
- **算法自检**：覆盖连通性、派单公平性、瞬移与偏离检测的回归测试

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run dev        # 开发服务器，默认 5174
```

打开 `http://127.0.0.1:5174/`。生产构建用 `npm run build`，产物在 `dist/`，可由任意静态服务器托管。

仿真与自检直接在本地运行，无需启动服务：

```bash
npm run sim
npm run test:sim
```

GitHub Codespaces 已配置好环境与端口转发，打开仓库即可运行。
